👋 Welcome to your new ChatOSS app

This is the starter template for a .aip app — a folder of plain HTML, CSS, and JavaScript with an app.json manifest, zipped and installed into ChatOSS. No frameworks, no build step, no npm.

How building a .aip app works

  1. Edit the files in the left sidebar — index.html is the entry point, style.css holds your styles, and app.json is the manifest.
  2. The live preview (right side in Create mode, or install the .aip to run it for real) shows your app exactly as it will run in the ChatOSS sandbox.
  3. Use the AI chat (middle column) to ask an agent to build or modify features for you. The agent can read and write these files.
  4. When you're done, Publish packages the folder into a .aip and installs it in your dock.

Suggested design pattern

This template uses the standard ChatOSS three-column layout that works well for most project- or collection-based apps:

  • Left — files / project library: list, create, and select the things your app organizes.
  • Middle — AI chat: a model picker from window.chatoss.chat.listModels() plus per-project chat history, with the current project state included in the system message.
  • Right — app content / canvas: the product-specific surface. This is the only column that should fundamentally change between apps — replace it with your own UI.

Small single-purpose utilities may drop the pattern, but it is the default. Keep a light, clean look (system-ui font, hairline borders, one accent color) and define dark colors under @media (prefers-color-scheme: dark) so ChatOSS Light/Dark flows through.

Where to find documentation

  • AGENTS.md in this project contains the full ChatOSS .aip app guide — every window.chatoss.* API, the manifest schema, capabilities, and permissions. The AI agent reads it automatically.
  • The Docs app in your ChatOSS dock has an API reference and a worked example (Sticky Notes) you can study and install.
