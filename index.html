Settings

Defaults

Defaults pre-fill the spawn modal — it always appears and you can change anything before starting.

Model Selection Mode

Choose how sub-agent sessions pick their launch target. Options include the direct claude / codex CLIs (when installed) and ollama models from ollama list. Each target can also carry an Effort level: applied when the session starts — Codex gets its real model_reasoning_effort flag; agents without an effort flag (claude / opencode / ollama) get an effort instruction added to the task brief instead.

You'll be asked to pick a launch target (claude / codex direct, or an ollama model) each time a session starts. Effort levels saved in the other modes still apply per target when it launches.

Folder trust

When a coding agent (Claude Code, Codex, etc.) asks to "trust this folder" at startup, Term Coder can ask you in chat before confirming, or always trust automatically.
