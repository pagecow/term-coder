Click "Code" in the top right corner, then click "Download ZIP".

Then drag and drop the term-coder-main.zip file into ChatOSS Apps > Library to install and use Term Coder in the ChatOSS desktop app.

Term Coder only runs on the ChatOSS desktop app.

**Requirement:** Term Coder launches its coding agents (OpenCode, Claude Code, Codex) through the `chatoss` command. If it isn't installed, go to ChatOSS **Settings → Launch → "Install chatoss command"** and click that — Term Coder can't start agents without it. The ChatOSS desktop app must also be running (it hosts the local model server the agents use).

You can download the ChatOSS desktop app here: https://chatoss.ai

You can also git clone the project to open the app in the ChatOSS Create app to have the ability to update the app if you want any additional features.

Term Coder is open source. PRs are welcome.
